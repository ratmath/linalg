Tool

Exact workbench

A scratchpad for the library. Type numbers into named matrices, then write expressions or press an operation. Numbers sets what may appear. Rational is the default, and every answer is an exact fraction. Turn on real algebraic and roots appear too: √2, eigenvalues, singular values, each held exactly as a polynomial with an interval around just that root, and they add, multiply and divide exactly. Complex adds the complex roots, shown in certified boxes. Ranges lets entries be intervals like 1:1.1 and gives enclosures, including exp(A). Mod p computes in the integers modulo a prime.

Functions

The same work from JavaScript

import { Matrix, det, inverse, solve } from "@ratmath/linalg";

const A = Matrix.from([[1, 2, 3], [4, 5, 6], [7, 8, 10]]);
det(A).exact().toString();                 // "-3"
inverse(A).exact().toStrings();            // [["-2/3","-4/3","1"], ["-2/3","11/3","-2"], ["1","-2","1"]]
solve(A, [1, 2, 3]).exact().x.toStrings(); // [["-1/3"], ["2/3"], ["0"]]
