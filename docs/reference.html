Reference

Everything in the library

Entries can be numbers, bigints, strings such as "3/4", "1.25" or "0.#3" (Core's literal grammar), or Core Rationals. A decimal JS number is read by its shortest spelling, so 0.1 means 1/10. Functions marked R return a Refinement: read .quick for the preview and call .exact() or await .settle() for the exact value.

Teaching forms

teach.* returns { title, summary, steps, result }; each step is plain data (title, text, the matrix with highlights, tables). Available: gaussJordan, solveSystem, inverse, determinantByElimination, cofactorExpansion, bareiss, modularDeterminant, guessAndCheck, gramSchmidt, lu, leastSquares, eigen, sturmWalk, jordanBlocks, powerBySquaring, exponentialSeries, newtonKrawczyk, fourSubspaces, dixonLifting, and the interactive RowReducer.
