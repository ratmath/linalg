@ratmath/linalg

Exact answers, without the wait

A JavaScript linear algebra library for exact rational arithmetic. Every computation answers twice: a floating-point preview in about a millisecond, then the exact answer, which is the one that stays.

Move the slider. The preview follows your hand, computed in ordinary floating point. When you stop, the exact solution arrives as fractions. If you keep moving, the exact work for positions you have already left is dropped, so nothing piles up.

Why both

Exact arithmetic is the point of RatMath: 1/3 stays 1/3, a singular matrix is singular for certain, and a determinant is an integer you can trust. But exact arithmetic costs more, and someone dragging a slider wants a picture now, not a proof. So the library gives each operation a fast form and an exact form, and a small protocol, the Refinement, that lets a page show the first and settle on the second.

Some answers are not rational, such as eigenvalues like √3 or entries of exp(A). The library still gives them exactly: as a polynomial together with an interval holding exactly one of its roots, or as an interval certain to contain the true value. You choose how many digits to see.

Two ways to use it

The main functions are built for computing: they are fast and return values. The teach module is built for explaining. It runs the textbook algorithms one step at a time and describes each step in words. Every topic page below uses both: the panel on the right of each demo is the fast library, and Step by step opens the teaching form.

import { solve, det, eigenvalues, teach } from "@ratmath/linalg";

const job = solve([[2, 1, 1], [1, 3, 2], [1, 0, 0]], [4, 5, 6]);
job.quick.value.x;    // [[6], [15.000000000000004], [-23.000000000000004]]
job.exact().x;        // Matrix [[6], [15], [-23]]

det([["1/2", "1/3"], ["1/4", "1/5"]]).exact();   // Rational 1/60
eigenvalues([[1, 1], [1, 0]]).exact().real[1].value.toString(30);
                      // "1.618033988749894848204586834365…"

teach.solveSystem([[2, 1], [1, 3]], [1, 2]).steps;   // each row operation, explained

Ideas

Fast, then exact

Every operation returns a Refinement. Reading job.quick runs a floating-point version at once. The exact version is a generator that does a small unit of work (one pivot, one prime) and then yields, so it can run in slices between frames and stop as soon as nobody needs it.

const job = det(A);
job.quick;              // { stage: "float", value: -0.9999999999999998, trust: "good" }
await job.settle({      // runs in 8 ms slices, gives the page a turn in between
  signal,               // abort when the input changes
  onStage: (s) => draw(s),
});                     // Rational -1

How far to trust a preview

Each preview carries a trust label. good means the matrix is well conditioned and the digits shown are very likely right. rough means it is ill conditioned: the shape of the answer is right but trailing digits are not. unsure means a decision (is this pivot zero? what is the rank?) fell inside rounding noise, so the exact answer may even be a different kind of answer. A display can show rough previews with fewer digits and mark unsure ones as provisional.

Try the Hilbert-like entries 1/1, 1/2, 1/3 in each row, shifted by one each row, to see trust drop to rough. Make two rows equal to see unsure and a status change once the exact answer lands.

Sliders: live

const update = live((t) => solve(A(t), b), (stage) => draw(stage), { idleMs: 30 });
slider.oninput = () => update(slider.value);

Each update shows the preview immediately. The exact pass starts once the input has been still for idleMs, and a newer update cancels it. The demo on the introduction is exactly this.

Workers

For long exact computations, the exact stage can run in a Web Worker while the preview stays on the page. Results travel as plain data and come back as the same classes, so an eigenvalue from a worker can still be refined.

// worker.js
import { serveLinalg } from "@ratmath/linalg/worker";
serveLinalg(self);

// page
import { workerClient } from "@ratmath/linalg/worker";
const la = workerClient(new Worker("worker.js", { type: "module" }));
const job = la.eigenvalues(A);   // job.quick is ready now
const exact = await job.settle();

Shared shape

The same Refinement class is used by the RatMath graphics and analytic libraries, so a calculator can drive a graph, a solve and an integral with one loop.

Topic

Elimination and solving

A system of linear equations is a matrix of coefficients. Three row operations never change its solutions: swapping two rows, multiplying a row by a nonzero number, and adding a multiple of one row to another. Gauss–Jordan elimination uses them to reach reduced row echelon form: each nonzero row starts with a 1, that 1 is alone in its column, and the leading 1s step to the right going down.

From that form everything can be read: the rank is the number of pivots, the pivot columns of the original matrix span its column space, and each column without a pivot is a free unknown.

Reading a solution

Augment A with b and reduce. A row 0 0 … 0 | c with c ≠ 0 says 0 = c: no solution. Otherwise each pivot row gives one pivot unknown in terms of the free ones. With no free unknowns the solution is unique; with k free unknowns the solutions form a k-dimensional family.

Do it yourself

Choose the operations yourself. The reducer applies them exactly, keeps a history you can undo, says when you have reached echelon and reduced form, and can suggest the step Gauss–Jordan would take next.

What the fast version does differently

Textbook elimination divides as it goes, and the fractions grow quickly. The library instead clears denominators row by row and uses fraction-free (Bareiss) elimination, which keeps every number an integer minor of the input. For square systems it first tries to guess the answer from floats and check it exactly, and for large systems it uses p-adic lifting.

Topic

Determinants

The determinant of a square matrix is the signed volume scale of the map it describes. It is zero exactly when the columns are dependent, which is why it decides invertibility. There are several ways to compute it, and comparing them shows why exact computation needs care.

Cofactor expansion

det A = Σ (−1)^(1+j) a₁ⱼ det M₁ⱼ, where M₁ⱼ is A without row 1 and column j. It is the definition most courses start from, but it needs about n! multiplications, so it is only for small matrices.

Elimination

Row operations change the determinant in known ways: a swap flips its sign, adding a multiple of a row changes nothing, scaling a row scales it. Reduce to triangular form and multiply the diagonal: about n³/3 operations.

Fraction-free elimination

Elimination over the rationals creates fractions whose numerators and denominators can grow very fast. Bareiss's method works with integers only: each update is (p·a − b·c) divided by the previous pivot, and that division is always exact because every intermediate entry is a minor of the original matrix (Sylvester's identity). The numbers never grow larger than the minors themselves.

Primes and the Chinese remainder theorem

Hadamard's inequality bounds |det A| by the product of the row lengths. So instead of one computation with large numbers, compute det A modulo several primes, where every number stays small, and combine the residues with the Chinese remainder theorem until the product of the primes passes twice the bound. The library uses primes just below 2²⁶, so all the O(n³) work happens in ordinary floating-point registers; the demo uses small primes so the residues are readable.

Topic

Inverses and fast exact solving

Row reduce the augmented matrix [A | I]. If the left half becomes I, the same operations applied to I built A⁻¹ on the right. If a pivot is missing, A is singular.

Guess, then check

Calculator problems usually have answers with small denominators. So the library first solves in floating point, turns each value into the nearest simple fraction with continued fractions, and checks A·x = b exactly. The check takes about n² exact operations, much less than elimination, and a modular determinant test proves A is nonsingular so the answer is the only one. A guess is never returned without the check.

p-adic lifting

For larger systems whose answers are not simple, the library inverts A once modulo a prime p and then peels off the solution one base-p digit at a time: xᵢ = A⁻¹r mod p, then r ← (r − A·xᵢ)/p. After k digits the partial sum satisfies A·X ≡ b mod pᵏ, and rational reconstruction (the extended Euclidean algorithm, stopped halfway) turns it into fractions. An exact check decides when enough digits have been found. This is Dixon's method; it beats elimination from about 60×60 upward.

Topic

Eigenvalues and eigenvectors

λ is an eigenvalue of A when A − λI is singular, that is, when λ is a root of the characteristic polynomial det(λI − A). Its roots are usually irrational, so an exact library has to decide what an exact irrational answer is.

The characteristic polynomial

The library reduces A to Hessenberg form (zeros below the first subdiagonal) by similarity transforms, which keeps the eigenvalues, and reads the polynomial off with a short recurrence. It does this modulo primes and joins the results, like the modular determinant, so the polynomial is exact and the work is fast.

Exact irrational numbers

Repeated roots are split off with gcd(p, p′). For each remaining square-free factor, Sturm's theorem counts its real roots in any interval exactly. Bisecting until each interval holds one root gives an AlgebraicReal: the polynomial plus an interval. That pair is the exact number. Refining it is bisection, one bit per step, so you can ask for as many digits as you like, and the library also decides exactly whether the root is rational.

Complex eigenvalues

Sturm's count also tells how many roots are not real. Floating-point root finding locates them; then the Krawczyk test, applied to p(x + iy) = 0 as two real equations, proves each small box holds exactly one root. Checking that the boxes do not overlap accounts for every root. Try a rotation such as 0 −1 / 1 0 in the demo above.

Eigenvectors over Q(λ)

For a rational eigenvalue the eigenvectors are the null space of A − λI, computed exactly. For an irrational one, the columns of the adjugate of λI − A are eigenvectors, and the adjugate of xI − A is a polynomial in x with rational matrix coefficients (Faddeev–LeVerrier). So each entry of an eigenvector is a polynomial in λ: an exact element of Q(λ). Reduce it modulo λ's polynomial and it has low degree.

Topic

Jordan and canonical forms

Two matrices are similar (B = P⁻¹AP) when they describe the same map in different coordinates. The eigenvalues do not settle similarity, because a repeated eigenvalue can come with fewer independent eigenvectors than its multiplicity. The complete answer is the list of invariant factors: the Smith normal form of xI − A over the polynomials with rational coefficients.

  • The last invariant factor is the minimal polynomial, the lowest-degree polynomial that sends A to 0.
  • Putting the companion matrix of each invariant factor on the diagonal gives the rational canonical form. It is always rational, whatever the eigenvalues.
  • Splitting each invariant factor into square-free parts gives the Jordan block sizes of every eigenvalue, irrational and complex ones included.

Blocks from kernel dimensions

For a single eigenvalue λ, let N = A − λI. The number of Jordan blocks of size at least k equals dim ker Nᵏ − dim ker Nᵏ⁻¹. When λ is rational the library also builds Jordan chains (v, Nv, N²v, …) and from them the matrix P with A = PJP⁻¹, checked exactly.

Topic

Orthogonality and least squares

Gram–Schmidt without square roots

Gram–Schmidt makes a set of vectors perpendicular by subtracting from each its projections onto the earlier ones: q = a − Σ (a·qₖ)/(qₖ·qₖ) qₖ. Projections need no square roots, so if you skip the final normalization everything stays rational. The library's exact QR is this form: A = QR with Q's columns orthogonal and R unit upper triangular, plus the squared lengths. Dividing by their square roots gives the usual orthonormal QR, which is what the float preview shows.

Least squares

When there are more equations than unknowns, A·x = b usually has no solution. The best x makes the error b − A·x as short as possible, which happens when the error is perpendicular to every column of A: AᵀA·x = Aᵀb. For rational data the answer is rational, so the library returns it exactly, along with the residual.

The pseudoinverse

A⁺ gives the least-squares solution of least length for any A, even when columns depend on each other. For a rational matrix it is rational: with A = C·F a full-rank factorization (C the pivot columns, F the nonzero rows of the reduced form), A⁺ = Fᵀ(FFᵀ)⁻¹(CᵀC)⁻¹Cᵀ.

Singular values

The singular values are the square roots of the eigenvalues of AᵀA. The library isolates the eigenvalues of the smaller of AᵀA and AAᵀ exactly, then maps each isolating interval through the square root, so each singular value is an exact algebraic number. U and V are irrational in general and are given in floating point.

Topic

Factorizations and powers

LU

Elimination below the pivots, with each multiplier saved where it cleared an entry, writes PA = LU: L lower triangular with 1s on the diagonal, U the echelon form, P the row swaps. Solving with a new right side then costs only two triangular solves.

LDLᵀ

A symmetric matrix factors as L·D·Lᵀ with D diagonal. This is Cholesky without the square roots, so it stays exact, and the signs of D tell whether A is positive definite.

Powers by squaring

Aᵏ needs only about 2·log₂k multiplications: square A repeatedly and multiply together the powers that match the 1 bits of k. Negative powers use the inverse.

Topic

Integer matrices

Over the integers you may only divide when the result stays an integer, so the allowed row operations are swaps, adding integer multiples, and multiplying by ±1. These are the unimodular operations.

The Hermite normal form is the integer version of the reduced echelon form: pivots positive, entries above each pivot reduced to the range [0, pivot). It identifies the lattice spanned by the rows. The Smith normal form allows column operations too and reaches a diagonal d₁, d₂, … with each dividing the next. It describes the abelian group ℤⁿ / (row lattice), and so answers which integer systems A·x = b have integer solutions.

Topic

The matrix exponential

exp(A) = I + A + A²/2! + A³/3! + … solves the linear differential equation x′ = Ax: x(t) = exp(tA)·x(0). Its entries are rarely rational, so the exact stage returns an interval for each entry that certainly contains the true value.

The method is scaling and squaring. Divide A by 2ˢ so its norm is at most 1/2, sum the Taylor series in exact interval arithmetic, add a proven bound for the rest of the series to every entry, then square s times. Endpoints are rounded outward to a binary grid so their size stays under control. The intervals come back narrower than 2⁻ᵇⁱᵗˢ.

Topic

Nonlinear solving

Nonlinear solvers keep returning to linear algebra. Newton's method solves a linear system with the Jacobian at every step. Proving that a root exists, and that there is only one, needs linear algebra with intervals.

Newton and the Krawczyk test

Newton's method converges fast but proves nothing. Running it in exact rationals proves nothing either, and the denominators roughly double each step. The Krawczyk test turns an approximate root into a certificate. Take a box X around it, its midpoint m and Y ≈ J(m)⁻¹. Then compute K(X) = m − Y·f(m) + (I − Y·J(X))(X − m) in exact interval arithmetic. If K(X) lies inside X, X contains exactly one root. If K(X) misses X, there is no root there. Repeating the step shrinks the box quadratically.

certifyRoot does this for systems: you give f (exact at rational points) and an interval enclosure of the Jacobian over a box. The preview is float Newton; the exact stage is the certified box.

Uncertain coefficients

When the entries of A and b are only known to lie in ranges, solveIntervals returns a box that contains the solution of every system in the range, and proves that every matrix in the range is invertible. This is the same Krawczyk test with f(x) = A·x − b.
